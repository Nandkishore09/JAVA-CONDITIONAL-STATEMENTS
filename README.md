# ☕ Java Basics Practice

This repository contains my Java practice programs while learning the fundamentals of Java programming. The goal of this repository is to strengthen my core programming concepts by solving simple problems and practicing syntax.

## 📚 Topics Covered

- Java Syntax
- Variables & Data Types
- User Input (`Scanner`)
- Conditional Statements (`if`, `else if`, `else`)
- Switch Case Statements
- Comments

## 📂 Current Programs

### 1. Age Checker
This program:
- Takes age as input from the user.
- Checks if the age is greater than 18.
- Prints `adult` if true, otherwise prints `Not adult`.

**Example**

Input
```
20
```
Output
```
adult
```

### 2. Even or Odd / Greater or Lesser
This program:
- Takes two integers, `a` and `b`, as input from the user.
- Compares the two numbers.
- Prints `equal` if they are the same, `a is greater` if `a` is bigger, or `a is lesser` otherwise.

**Example**

Input
```
15
10
```
Output
```
a is greater
```

### 3. Switch Case - Greeting Selector
This program:
- Takes a number (button) as input from the user.
- Uses a `switch` statement to print a greeting based on the input.
  - `1` → hello
  - `2` → namaste
  - `3` → bonjour
  - anything else → Invalid button

**Example**

Input
```
2
```
Output
```
nameste
```

## 🚀 How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/java-basics.git
   ```

2. Open the project in VS Code or any Java IDE.

3. Compile the program
   ```bash
   javac condition.java
   ```

4. Run the program
   ```bash
   java condition
   ```

5. Enter the required input when prompted based on the active program.
